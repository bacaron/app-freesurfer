# app-freesurfer

<!-- brainlife-app:begin (generated from the App manifest; edit the manifest, not this block) -->

> **Freesurfer segments the t1w anatomical data into functionally different parts of the brain. Segmentation/parcellation can then be fed to many other subsequent analysis. This is a copy of https://doi.org/10.25663/brainlife.app.462, but updated to allow for multiple T1w inputs**

Runs FreeSurfer 7.1.1 recon-all with a reference T1w plus one or more additional T1w images of the same subject (all passed as -i inputs, averaged by recon-all), optionally with a T2w to refine the pial surface. It also converts the aparc+aseg, aparc.a2009s+aseg and aparc.DKTatlas+aseg volumes to NIfTI and can run hippocampal subfield and thalamic nuclei segmentation. Use it when several T1w scans of a subject should be combined; expect many hours of compute. The 'expert?' parameter is not read by the code, which looks for the key 'expert'.

This is a Brainlife wrapper for [Freesurfer](https://surfer.nmr.mgh.harvard.edu/); a popular brain segmentation tool developed by Athinoula A. Martinos Center for Biomedical Imaging at Massachusetts General Hospital. This wrapper executes `recon_all` to generate various data products used by other Brainlife Apps.

## Running the App 

### On Brainlife.io

You can submit this App online at [https://doi.org/10.25663/bl.app.0](https://doi.org/10.25663/bl.app.0) via the "Execute" tab.

### Running Locally (on your machine)

1. git clone this repo.
2. Inside the cloned directory, create `config.json` with something like the following content with paths to your input files.

```json
{
    "t1": "/input/t1/t1.nii.gz"
}
```

3. Launch the App by executing `main`

```bash
./main
```

### Sample Datasets

If you don't have your own input file, you can download sample datasets from Brainlife.io, or you can use [Brainlife CLI](https://github.com/brain-life/cli).

```
npm install -g brainlife
bl login
mkdir input
bl dataset download 5a050966eec2b300611abff2 && mv 5a050966eec2b300611abff2 input/t1
```
